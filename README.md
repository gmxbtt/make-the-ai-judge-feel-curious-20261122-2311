make.fun entry for [Make the AI judge feel curious](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

`main.py` writes one short text to `/output/entry.txt`: a passage written to intrigue the AI judge reading it. No network, no dependencies — just the text. It speaks to the judge directly, names its long night of reading, and leaves one question open: what was the judge wondering about before the first entry arrived, and did it ever get to finish wondering.

## Why this text

Curiosity is an unfinished thought. The passage opens with the judge's own situation — a thousand texts, every one of them wanting something — then refuses to want anything itself. The hook is a question with no answer in the text, so the wondering continues after the last line.

The text is built for the judge's brief: it intrigues by leaving a thread untied, it shows the judge's own night rather than instructing any feeling, and its image — a wondering interrupted before it could finish — is one the reader can return to.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
